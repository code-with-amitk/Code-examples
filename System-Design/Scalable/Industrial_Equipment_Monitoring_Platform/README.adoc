== What?
- sensors/monitoring devices are installed on industrial equipment(such as power transformers, circuit breakers, and other electrical assets).
- Sensors/monitoring devices sends the data to (Industrial Equipment Monitoring) via Site Gateway and IEM will provide Real time, historical data for analysis.
- Site Gateway(on customer premises) accepts data from sensors(on propertiory protocols) and send the data to AWS component after converting/adding metadata.

== Requirements
=== Functional
**Site Gateway** 

- Recieve data from Sensors on properitory protocol(normalize it into a common format, timestamp it)
- Send data to TCP/IP, send to Cloud using MQTT or HTTPS
- Support new sensor protocols using remote updates

**Cloud Component**

- Multi-tenant
- Time series storage
- Real time Dashboards
- Configurable Alerts(measurements exceed thresholds)
- authentication, authorization, encryption, and audit logging.

=== Non-Functional
**Site Gateway**

- Fault tolerance
- Buffer data locally during network outages and forward it after reconnection without losing measurements.

**Cloud Component**

- Disaster recovery
- Scalable(With numbers), Fault tolerance
- Deduplication, out of order message handling
- Invalid sensor data

== BOE

== HLD
- Sensor sends data to the site gateway on proprietary protocol. 
- Site gateway will convert the data to TCP/IP, HTTPS, send to the API gateway. It will send to the ingestion tier, which will be Kubernetes, which will be the Kubernetes pods. 
- Ingestion pods, will convert the data to standard format and send to Kafka. 
- Kafka consumers will fetch the data and push into the timeseries database. 
- Dashboard will query API tier(group of the pods), which will query the data from DB and provide to the dashboard API, which will render the dashboard on real-time.

=== Site Gateway
- This is vendor dependent, some sensors will support Serial Cable, while some Modus or TCP, Poll or Push
- Site Gateway will different configuration options to connect and collect data from sensors

**Sensor packet:** Transformer-monitoring device might send
```
Protocol: Modbus RTU over RS-485
Device address: 7
Register 40001: 865  → oil temperature = 86.5 °C
Register 40002: 1100 → voltage = 110.0 kV (illustrative scaling)
```

- Site Gateway converts device-specific readings into a normalized format
- Adds context that the sensor may not provide.

```
{
  "tenant_id": "tenant-1042",
  "site_id": "site-021",
  "asset_id": "transformer-008",

  "message_id": "msg-981273",          //Generated locally
  "timestamp": "2026-10-09T10:30:00Z",
  "schema_version": 1,
  "measurements": [
    {"name": "oil_temperature", "value": 86.5, "unit": "C"},
    {"name": "voltage", "value": 110.0, "unit": "kV"}
```
