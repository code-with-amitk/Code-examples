== HTTP Request Parser
- Netskope style forward proxy has gateways: PAC file gateway for receiving traffic from PAC browser, VPN gateway for receiving traffic from VPN client.
- Raw bytes/chunks are received on the interface/socket
- HTTP Request Parser will convert these bytes/chunks to HTTP.
