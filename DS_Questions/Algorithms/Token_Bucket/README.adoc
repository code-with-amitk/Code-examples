= Bucket Algorithms
Languages written in: Go, C++, Java, Rust

|===
|Algorithm|What|Production Dominance|Where Deployed|Problem with this Algorithm|Solved Using
|link:Fixed_Window_Counter[Fixed Window Counter]|Allow fixed number of request/user per timeslice|||Boundary Burst Problem|Sliding Window Log

|link:Sliding_Window_Log[Sliding Window Log]|Tracks exact timestamp of every single request, it looks backward on a rolling time window|||Memory Overhead|Sliding Window Counter

|link:Sliding_Window_Counter[Sliding Window Counter]|Uses 2 counters (request_count_in_prev_window, request_count_in_present_window)|||Approximation Error|Token Bucket

|link:Token_Bucket[Token Bucket]|Tokens filled into bucket at a fixed rate| * * * * * Highest|Rate Limiters, API Gateway||

|Token Bucket with Leaky Rate Control((Lazy-Refill variant)|Instead of active background timers, token counts are calculated using the time difference (timestamp_now - timestamp_last_request)| * * * Very High|Envoy Proxy, Nginx||

|Leaky Bucket(Queue / Blocking variant)|Requests flow into a queue bucket. The system extracts and executes them at a perfectly uniform, steady pace.| * * Medium|Uber Engine, Shopify||
|===
