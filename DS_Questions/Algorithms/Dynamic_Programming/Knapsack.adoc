= Knapsack Optimization Problem

== What
Knapsack is not a algorithm, but it is a optimization problem where you pick items with given weights and values & try to MAXIMIZE total VALUE without exceeding a weight limit.

=== Example
Suppose your bag can hold at most 5 kg, and you have 3 items (you must take a whole item or leave it):
```
• Camera: 3 kg, value ₹600
• Laptop: 4 kg, value ₹800
• Water bottle: 2 kg, value ₹300
```

**How to choose?**

- 4 kg, 800(Laptop) + 3 kg, 600(Camera). Value becomes max=1400. But 3+4>5. Cannot choose
- Laptop+Water bottle. No
- Camera + Bottle. Yes

== Types of Knapsack & how to solve
|===
|Type|What|Solved Using

|0/1 Knapsack problem(Most common)
|You must either take an entire item (1) or leave it behind (0)—you cannot break items into smaller pieces or take multiples of the same item.
|Dynamic Programming

|Fractional Knapsack
|You can break items into smaller pieces and take a fraction of them
|Greedy

|Bounded knapsack
|Each item has a specific, limited quantity available (e.g., 3 identical laptops)
|DP

|Multiple knapsack
|You have more than one bag (knapsack), each with its own weight limit
|DP

|Multi-dimensional Knapsack
|Each item has multiple constraints (e.g., both weight and volume limits).
|DP or Heuristic Algorithms.
|===
