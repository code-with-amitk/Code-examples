== link:https://leetcode.com/problems/smallest-missing-multiple-of-k/description/[3718. Smallest Missing Multiple of K]
Given an integer array nums and an integer k, return the smallest positive multiple of k that is missing from nums.

A multiple of k is any positive integer divisible by k.
 
```
Example 1:
Input: nums = [8,2,3,4,6], k = 2
Output: 10
Explanation: The multiples of k = 2 are 2, 4, 6, 8, 10, 12... and the smallest multiple missing from nums is 10.

Example 2:
Input: nums = [1,4,7,10,15], k = 5
Output: 5
Explanation:The multiples of k = 5 are 5, 10, 15, 20... and the smallest multiple missing from nums is 5.
```

== CPP
- Insert array elements(nums) in map
- Search multiples in map.
- Start from k and keep searching multiples (k, k1, K2 ...) until multiple is missing from us

=== Complexity
- Time complexity: O(m). m=multiples of k present in nums
- Space complexity: O(n). n=size(nums)

```cpp
class Solution {
public:

    int missingMultiple(vector<int>& nums, int k) {
        unordered_set<int> us;
        int least_number = 1;
        for (auto&i:nums) {
            us.insert(i);
        }
        int i=2;
        int multiple = k;
        while(1) {
            if (us.find(multiple) != us.end()) {
                multiple = k*i;
            } else {
                break;
            }
            i++;
        }
        return multiple;
    }
};
```
