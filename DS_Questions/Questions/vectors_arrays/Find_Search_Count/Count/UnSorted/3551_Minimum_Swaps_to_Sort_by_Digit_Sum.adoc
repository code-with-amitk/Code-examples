== link:https://leetcode.com/problems/minimum-swaps-to-sort-by-digit-sum[3551. Minimum Swaps to Sort by Digit Sum]
You are given an array nums of distinct positive integers. You need to sort the array in increasing order based on the sum of the digits of each number. If two numbers have the same digit sum, the smaller number appears first in the sorted order.

Return the minimum number of swaps required to rearrange nums into this sorted order.

A swap is defined as exchanging the values at two distinct positions in the array.

```
Example 1:
Input: nums = [37,100]
Output: 1
Explanation:
Compute the digit sum for each integer: [3 + 7 = 10, 1 + 0 + 0 = 1] → [10, 1]
Sort the integers based on digit sum: [100, 37]. Swap 37 with 100 to obtain the sorted order.
Thus, the minimum number of swaps required to rearrange nums is 1.

Example 2:
Input: nums = [22,14,33,7]
Output: 0
Explanation:
Compute the digit sum for each integer: [2 + 2 = 4, 1 + 4 = 5, 3 + 3 = 6, 7 = 7] → [4, 5, 6, 7]
Sort the integers based on digit sum: [22, 14, 33, 7]. The array is already sorted.
Thus, the minimum number of swaps required to rearrange nums is 0.

Example 3:
Input: nums = [18,43,34,16]
Output: 2
Explanation:
Compute the digit sum for each integer: [1 + 8 = 9, 4 + 3 = 7, 3 + 4 = 7, 1 + 6 = 7] → [9, 7, 7, 7]
Sort the integers based on digit sum: [16, 34, 43, 18]. Swap 18 with 16, and swap 43 with 34 to obtain the sorted order.
Thus, the minimum number of swaps required to rearrange nums is 2.
````

== Approach
```
[18,43,34,16]
0  1  2  3
```
- Create a tuple (sum, number, original_index)
```
original sum = 9,7,7,7
tuple = {9,18,0}, {7,43,1}, {7,34,2}, {7,16,3} 
```
- sort
```
{9,18,0}, {7,43,1}, {7,34,2}, {7,16,3} 
becomes
{7,16,3}, {7,34,2}, {7,43,1}, {9,18,0}
```
- Find cycles
** From index=0 in sorted array, jump to index entry
** On new entry jump to index
** if it come back to original node(That's Cycle) and that means, we need 1 swap operation to swap these elements
```
cycle
                |----------------------|
                \/                     |
            {7,16,3}                {9,18,0}
                |                    /\
                |-------index=3-------|
```

=== Complexity
- Time: O(nlogn)
- Space: O(n)

=== Code
==== CPP
```
// Element shape: tuple<digit_sum, value, original_index>
using Element = std::tuple<int, int, int>;class Solution {
int getDigitSum(int n) {
        int sum = 0;
        while (n > 0) {
            sum += n % 10;
            n /= 10;
        }
        return sum;
    }

public:
    int minSwaps(std::vector<int>& nums) {
        int n = nums.size();
        std::vector<Element> tup;
        tup.reserve(n);

        /* [18,43,34,16]
            0  1  2  3

            sum=9,7,7,7

            Create a tuple (sum, number, original_index)
            {9,18,0}, {7,43,1}, {7,34,2}, {7,16,3} 
        */
        for (int i = 0; i < n; ++i)
            tup.emplace_back(getDigitSum(nums[i]), nums[i], i);

        /*
        Sort the tuple
            {9,18,0}, {7,43,1}, {7,34,2}, {7,16,3} 
            becomes
             {7,16,3}, {7,34,2}, {7,43,1}, {9,18,0}
        */
        std::sort(tup.begin(), tup.end());

        /*
            Find cycles
            - From index=0 in sorted array, jump to index entry
            - On new entry jump to index
            - if it come back to original node(That's Cycle) and that means
                we need 1 swap operation to swap these elements
                |----------------------|
                \/                     |
            {7,16,3}                {9,18,0}
                |                    /\
                |-------index=3-------|
        */
        std::vector<bool> visited(n, false);
        int total_swaps = 0;

        // Traverse all elements to detect disjoint cycles
        for (int i = 0; i < n; ++i) {
            int orig_idx = std::get<2>(tup[i]);

            // Skip if already visited or already in correct sorted position
            if (visited[i] || orig_idx == i) {
                continue;
            }

            int cycle_size = 0;
            int curr = i;

            // Follow the cycle until we hit an already visited node
            while (!visited[curr]) {
                visited[curr] = true;
                curr = std::get<2>(tup[curr]);
                cycle_size++;
            }

            if (cycle_size > 1) {
                total_swaps += (cycle_size - 1);
            }
        }

        return total_swaps;
    }
};
```
