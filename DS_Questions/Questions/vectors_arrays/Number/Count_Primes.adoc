== link:https://leetcode.com/problems/count-primes/description/[Count Primes]
Given an integer n, return the number of prime numbers that are strictly less than n.

```txt
Example 1:
Input: n = 10
Output: 4
Explanation: There are 4 prime numbers less than 10, they are 2, 3, 5, 7.

Example 2:
Input: n = 0
Output: 0

Example 3:
Input: n = 1
Output: 0
```

== Brute Force (TLE)
=== Logic (check n i prime)
- Loop through every integer i from 2 up to n-1.
- For each integer check whether it is prime or not
```
  inner-loop through all integers j=2 to sqrt(n)
  if n is divisible by any integer then its not prime
```

=== CPP
```cpp
class Solution {
public:
    bool isPrime(int n) {
        if (n <= 1) return false;
        // Check divisors from 2 up to sqrt(n)
        for (int i = 2; i * i <= n; i++) {
            if (n % i == 0) {
                return false; // Return immediately if a divisor is found
            }
        }
        return true;
    }

    int countPrimes(int n) {
        int count = 0;
        // Start from 2 because 2 is the first prime number
        for (int i = 2; i < n; i++) {
            if (isPrime(i)) {
                count++;
            }
        }
        return count;
    }
};
```
