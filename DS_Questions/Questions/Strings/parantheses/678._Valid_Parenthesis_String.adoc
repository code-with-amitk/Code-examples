== link:https://leetcode.com/problems/valid-parenthesis-string/description/[678. Valid Parenthesis String]
Given a string s containing only three types of characters: '(', ')' and '*', return true if s is valid.

The following rules define a valid string:

Any left parenthesis '(' must have a corresponding right parenthesis ')'.
Any right parenthesis ')' must have a corresponding left parenthesis '('.
Left parenthesis '(' must go before the corresponding right parenthesis ')'.
'*' could be treated as a single right parenthesis ')' or a single left parenthesis '(' or an empty string "".
 
```
Example 1:
Input: s = "()"
Output: true

Example 2:
Input: s = "(*)"
Output: true

Example 3:
Input: s = "(*))"
Output: true

Example 4:
Input: s = "("
Output: false
```

== Stack Approach Does not Work
- When approaching standard parenthesis matching, a stack works because every character has an absolute, deterministic state: ( adds an obligation, and ) resolves the most recent obligation. 
- When you introduce * (which can be (, ), or ""), determinism breaks.
- If you attempt to use stacks, you encounter a state-space explosion
```
String: (*)
At index 0 (: Stack = ['(']
At index 1 *: The stack branches into 3 valid future states:
1. Act as ( => Stack becomes [((]
2. Act as ) => Stack becomes []
3. Act as "" => Stack remains [(]
```
- If you have k asterisks, branching creates up to 3^k states.

== Counting the brackets
- cmin: lower bound of open ( brackets currently waiting for closure. Hence at * decrement cmin by 1
```
Input Symbol	Min Open Count (cmin)	    Max Open Count (cmax)	    Underlying Assumption
(	            cmin + 1	                cmax + 1	                Mandatory open bracket added.
)	            cmin - 1	                cmax - 1	                Mandatory close bracket consumes an open bracket.
*	            cmin - 1	                cmax + 1	                Range expands: cmin assumes * = ), cmax assumes * = (.
```
=== CPP
```cpp
class Solution {
public:
    bool checkValidString(string s) {
        int cmin = 0; // Minimum open parentheses possible
        int cmax = 0; // Maximum open parentheses possible

        for (char c : s) {
            if (c == '(') {
                cmin++;
                cmax++;
            } else if (c == ')') {
                cmin--;
                cmax--;
            } else { // c == '*'
                cmin--; // Treat '*' as ')'
                cmax++; // Treat '*' as '('
            }

            // cmin cannot drop below 0 (we can't have negative open brackets)
            if (cmin < 0) {
                cmin = 0;
            }

            // If cmax drops below 0, we have too many ')' and no '(' or '*' to match them
            if (cmax < 0) {
                return false;
            }
        }

        // At the end, check if it's possible to have 0 unmatched open brackets
        return cmin == 0;
    }
};
```

=== Go
```go
func checkValidString(s string) bool {
        cmin := 0;
        cmax := 0;

        for _, c := range s {
            if c == '(' {
                cmin++
                cmax++
            } else if c == ')' {
                cmin--
                cmax--
            } else {
                cmin--
                cmax++
            }

            if cmin < 0 {
                cmin = 0
            }

            if cmax < 0 {
                return false
            }
        }

        return cmin == 0
}
```

```rs
impl Solution {
    pub fn check_valid_string(s: String) -> bool {
        let mut cmin = 0;
        let mut cmax = 0;

        for c in s.chars() {
            if c == '(' {
                cmin += 1;
                cmax += 1;
            } else if c == ')' {
                cmin -= 1;
                cmax -= 1;
            } else {
                cmin -= 1;
                cmax += 1;
            }

            if cmin < 0 {
                cmin = 0;
            }

            if cmax < 0 {
                return false;
            }
        }

        return cmin == 0;
    }
}
```
